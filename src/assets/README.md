# 앙두 실제 사진

사용자가 이 채팅에 첨부한 PNG 3장을 파일 내용 변경 없이 보존했습니다.

| 파일 | 실제 장면 | 주요 배치 | 표시할 세로 범위(원본 좌표) |
|---|---|---|---|
| andu-01.png | 분홍색 배경, 리본·검은 케이프, 나무 의자 | 홈 대표·초상 예시 | y=486~2250 |
| andu-02.png | 회색 바닥에 엎드린 모습, 작은 붉은 리본 | 앙두 소개·실내 일상 | y=528~2208 |
| andu-03.png | 나무가 우거진 흙길에 앉은 모습 | 산책 스토리·플레이스 | y=528~2208 |

원본은 모두 1260×2736px. 촬영 장소·날짜는 확인되지 않았으며 사진만으로 추정해 기록하지 않습니다.

`Photo.astro`에서 Astro getImage로 너비 1000px, 품질 82 WebP를 빌드합니다. 원본 자체를 수정하지 않고 SVG viewBox로 검은 상하 여백을 표시에서 제외합니다. 카드·상세·모바일은 slice 방식으로 컨테이너에 맞춰 표시합니다. 사진을 새로 교체하면 width/height 및 Photo.astro의 top/bottom 범위도 새 파일에 맞게 조정해야 합니다.

이미지 파일이 없거나 이름이 바뀌면 빌드가 실패하므로 참조를 함께 수정하세요. 새 원본을 공개 GitHub에 올리기 전 공개 범위를 확인합니다. 확정 A-2 로고는 별도 자료이며 현재 사진 반영만으로 심볼을 확정 로고로 변경하지 않았습니다.
